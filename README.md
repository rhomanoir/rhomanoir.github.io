# Страница с задачами

Шаблон повторяет простую структуру LaTeX-документа:

```tex
\section{Тема 1}

\paragraph{Задача 1.} Текст задачи.
```

Все темы и задачи хранятся в `tasks.js` и выводятся подряд на одной странице.

## Формулы LaTeX

Шаблон использует MathJax. Формулу внутри строки заключайте в одинарные знаки доллара:

```js
text: "Решите уравнение $x^2 - 5x + 6 = 0$.",
```

Отдельную формулу заключайте в двойные знаки доллара. Обратную косую черту внутри строки JavaScript нужно писать дважды:

```js
text: "Найдите значение: $$\\int_0^1 x^2\\,dx$$",
```

Чтобы добавить тему, скопируйте объект с полями `title` и `tasks`. Чтобы добавить задачу, скопируйте объект с полями `label` и `text`:

```js
{
  label: "Задача 4",
  text: "Новый текст задачи.",
}
```

Для публикации загрузите `index.html`, `styles.css`, `tasks.js` и `app.js` в корень Pages-репозитория.
